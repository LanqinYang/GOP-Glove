# Reproducibility files

The pseudonymised dataset, shared descriptor and explicit file partitions support the manuscript workflow. Use `configs/manuscript_protocol.json` for the common dataset, augmentation, gate and deployment settings.

```bash
python -m pip install -r reproducibility/requirements-features.txt
python scripts/export_reproducibility.py
python scripts/verify_reproducibility.py
```

| File or directory | Contents |
|---|---|
| `dataset_manifest.csv` | Recording filenames, participant/class/repetition IDs, sample counts and SHA-256 hashes |
| `generated/iid_seed42.csv` | 422 training, 106 validation and 132 test files |
| `generated/loso_seed42.csv` | Six LOSO folds: 440 training, 110 validation and 110 held-out-subject test files each |
| `generated/protocol_metadata.json` | File ordering, split settings and descriptor dimensions |
| `features.py` | Entry point for the shared 190-D descriptor |
| `generated/manuscript_unscaled_features.npy` | Feature array generated by the preparation command; scalers are fit during training |
| `results/` | Saved experiment outputs and parameter records |
| `source_manifest.json` | Source-file paths and SHA-256 hashes |

Training and evaluation read the same filename-based partitions through `splits.py`. The seed-stability workflow keeps these partitions fixed across the five seeds. Each run writes its actual computed metrics and prediction records to the chosen output directory.
